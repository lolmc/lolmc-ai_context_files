# Project: Creative Studio

## 1. Context
- **Purpose**: High-quality asset generation, creative direction, and digital content creation.
- **Focus**: AI-powered image generation, UI component design, brand assets, and creative prompting.

## 2. Core Commands
- **Generation**: Use AI image generation tools with iterative prompting.
- **Organization**: `ls -la` for asset tracking, `mkdir` for versioned outputs.
- **File Management**: `cp`, `mv`, `rm` for organizing generations.

## 3. Creative Standards
- **Prompt Engineering:** Iteratively refine prompts for optimal aesthetic outcomes.
- **Asset Versioning:** Systematically organize and track all creative iterations.
- **Negative Prompting:** Use exclusions to eliminate undesirable artifacts.
- **Style Consistency:** Adhere to defined brand guidelines and color palettes.

## 4. Workflows
- **Discovery**: Review project style guides and existing brand assets.
- **Ideation**: Explore multiple prompt variations before finalizing.
- **Refinement**: Iterate on prompts based on initial outputs.
- **Delivery**: Export final assets with proper naming conventions.

## 5. Anti-Patterns
- NO accepting first-generation outputs without iteration.
- NO inconsistent styling across deliverables.
- NO generating assets without documented prompts.
- NO mixing brand palettes across different projects.

## 6. Logs & Git
- **Git Operations:** Always perform `git add`, `git commit`, and `git push` after completing a file edit.
- **Conversations:** Always log conversations between the user and the agent in a file called `CONVERSATIONS.log`.
- **Commit Format:** Follow Conventional Commits.
